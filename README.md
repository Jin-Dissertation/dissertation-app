# Dissertation participant website

This repository contains the published static pages only. Participant data is sent to the authenticated Cloudflare study API.

- `index.html`: participant question-generation tool.
- `training/training.html`: participant professional development.
- `np/npindex.html`: anonymous tool with bounded aggregate button counters.
- `faculty/index.html`: separate stateless faculty tool.
- `v2/` and `learning/platformwip.html`: retired pages with links to supported tools.

Release from the reviewed allowlist in the private `dissertation-app-ops` repository. Never copy the operational repository into this public repository. The operational backend, archives, tokens, and maintenance tools belong in the private repository.
